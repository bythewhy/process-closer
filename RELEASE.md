# Process Closer 1.0.0

Это первая рабочая версия проекта.

Process Closer наблюдает за процессами текущего пользователя и завершает только
те экземпляры, которые совпали с заданными условиями. Условия можно задавать
именем, полным путём, SHA-256 файла и издателем Authenticode-подписи Windows.

В релиз входят два варианта запуска:

- `process-closer.exe` — собранное приложение для Windows;
- `main.py` — исходный вариант для Python 3.11+.

Для фонового запуска используется `--hide`. Этот режим убирает окно консоли, но
не отключает системный аудит и не скрывает процесс от Windows.

Автоперезапуск настраивается отдельно через Планировщик задач:

```powershell
python -m pip install -e ".[task]"
main.py --install-task Discord.exe --hide
```

Удалить задачу можно так:

```powershell
main.py --remove-task
```
